# tes3np Downloads

Public test downloads for **tes3np — Nerevarine Prophecies Launcher**.

> **Development software:** these packages are for testing and may contain bugs or incomplete features.

## Current version

**v0.1.0-alpha**

Windows test packages are published here so testers can download tes3np without access to the private development repository.

## Installation

1. Download the latest Windows package from this repository's **Releases** page.
2. Extract the ZIP completely.
3. Keep the included `tes3np` folder and all of its contents together.
4. Place the `tes3np` folder inside your TES3MP 0.8.1 Win64 folder.
5. Run `tes3np.exe`.

Morrowind GOTY and TES3MP 0.8.1 are required.

## Testing

If something fails, report the exact error message or provide a screenshot. Launcher patch errors are also written to `patch-errors.log` when available.
